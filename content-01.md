
# Class 01 - Cybersecurity Basics

## 1. Introduction to Cybersecurity

### Definition

Cybersecurity is the practice of protecting computers, networks, applications, and data from unauthorized access, cyberattacks, damage, or theft.

### Explanation

Cybersecurity ka matlab computers, networks, applications aur data ko hackers, viruses, malware aur doosre cyber threats se protect karna hai.

Aaj kal hum internet par banking, shopping, education aur communication ke liye depend karte hain. Is liye apni personal information aur digital devices ko secure rakhna bohat zaroori hai.

### Real-Life Example

Agar aapke email account par strong password aur Multi-Factor Authentication (MFA) enabled hai, to kisi doosre shakhs ke liye aapke account mein unauthorized login karna mushkil ho jata hai.

## 2. What Is Cybersecurity?

Cybersecurity aik process hai jisme technical tools, security policies aur safe practices use karke digital systems ko protect kiya jata hai.

### Main Objectives of Cybersecurity

- Data ko unauthorized access se protect karna.
- Computer systems ko attacks se bachana.
- Personal information ki privacy maintain karna.
- Network aur applications ko secure rakhna.
- Data ki availability aur integrity ko maintain karna.
- Cyberattacks ko detect karna aur unka response dena.

## 3. Why Is Cybersecurity Important?

Cybersecurity is liye important hai kyun ke hamara bohat sa personal aur business data digital form mein mojood hota hai.

### Importance

1. **Personal Data Protection:** Naam, phone number aur doosri personal information ko protect karna.
2. **Financial Security:** Online banking aur payment accounts ko secure rakhna.
3. **Business Protection:** Company ke important data aur systems ko attacks se bachana.
4. **Privacy:** Private information ko unauthorized logon se protect karna.
5. **System Availability:** Websites aur services ko available rakhne mein madad karna.
6. **Trust:** Customers ka apne digital systems par trust maintain karna.

### Example

Agar kisi bank ka system cyberattack ka shikar ho jaye, to customers ki information aur banking services affect ho sakti hain. Cybersecurity controls aise risks ko kam karne mein madad karte hain.

## 4. CIA Triad

CIA Triad cybersecurity ka aik basic security model hai. CIA ka matlab Confidentiality, Integrity aur Availability hai.

### 1. Confidentiality

**Definition:** Confidentiality ka matlab information ko sirf authorized logon tak mehdood rakhna hai.

**Explanation:** Data sirf woh log access kar saken jinhein uski permission di gayi ho.

**Example:** Aapke email account ka password doosre logon ko aapki permission ke baghair account access karne se rokne mein madad karta hai.

**Security Methods:**
- Encryption
- Access control
- Strong passwords
- Multi-Factor Authentication (MFA)

### 2. Integrity

**Definition:** Integrity ka matlab data ki accuracy aur completeness ko protect karna hai.

**Explanation:** Data ko unauthorized tareeqe se change, delete ya damage nahi hona chahiye.

**Example:** Bank account mein transaction ki amount unauthorized tareeqe se change nahi honi chahiye.

**Security Methods:**
- Hashing
- Digital signatures
- Access permissions
- Audit logs

### 3. Availability

**Definition:** Availability ka matlab authorized users ke liye systems aur data ko zaroorat ke waqt available rakhna hai.

**Explanation:** Website, application ya network service zaroorat ke waqt kaam karni chahiye.

**Example:** Online banking service customers ke liye available honi chahiye jab unhein apna account access karna ho.

**Security Methods:**
- Regular backups
- System maintenance
- Redundancy
- Disaster recovery
- DDoS protection

### CIA Triad Summary

| Principle | Meaning | Example |
|---|---|---|
| Confidentiality | Data ko unauthorized access se bachana. | Password aur encryption. |
| Integrity | Data ko accurate aur complete rakhna. | Transaction ki amount ko protect karna. |
| Availability | System aur data available rakhna. | Website ko operational rakhna. |

## 5. Types of Cybersecurity

### 1. Network Security

Network security ka maqsad network aur us se connected devices ko unauthorized access aur attacks se protect karna hai.

**Example:** Firewall aur secure Wi-Fi configuration.

### 2. Application Security

Application security mein software aur applications ko vulnerabilities aur attacks se protect kiya jata hai.

**Example:** Secure coding aur software updates.

### 3. Information Security

Information security ka maqsad information ki confidentiality, integrity aur availability ko protect karna hai.

**Example:** Sensitive files ko encrypt karna aur access permissions set karna.

### 4. Cloud Security

Cloud security mein cloud par mojood data, applications, accounts aur infrastructure ko protect kiya jata hai.

**Example:** AWS IAM permissions aur security groups ko sahi configure karna.

### 5. Endpoint Security

Endpoint security computers, laptops, mobile phones aur doosre end-user devices ko protect karti hai.

**Example:** Antivirus aur endpoint detection tools.

### 6. Identity and Access Management (IAM)

IAM users ki identities aur unki permissions ko manage karta hai.

**Example:** Har employee ko sirf uske kaam ke mutabiq system access dena.

## 6. What Is a Cyber Threat?

### Definition

A cyber threat is a potential event, action, or circumstance that can cause harm to a computer system, network, or data.

### Explanation

Cyber threat aisa potential khatra hota hai jo computer, network ya data ko nuqsan pohancha sakta hai.

### Examples of Cyber Threats

- Phishing attacks
- Malware
- Ransomware
- Password attacks
- Denial-of-Service attacks
- Social engineering

## 7. Common Types of Cyberattacks

### 1. Phishing

Phishing aik attack hai jisme attacker fake email, message ya website ke zariye user se sensitive information hasil karne ki koshish karta hai.

**Example:** Aapko fake bank message milta hai jo aapse password ya OTP mangta hai.

**Protection:**
- Sender ka address check karein.
- Unknown links par click na karein.
- Password aur OTP kisi ke saath share na karein.
- Official website ya application se account check karein.

### 2. Malware

Malware malicious software ko kehte hain jo system ya data ko nuqsan pohanchane, chori karne ya unauthorized access hasil karne ke liye banaya jata hai.

**Examples:**
- Virus
- Worm
- Trojan
- Spyware
- Ransomware

**Protection:**
- Trusted sources se software install karein.
- Operating system aur applications update rakhein.
- Security software use karein.
- Unknown attachments open karne se bachein.

### 3. Ransomware

Ransomware aik qisam ka malware hai jo files ko encrypt kar sakta hai aur unhein restore karne ke badlay ransom mang sakta hai.

**Example:** Company ki files open nahi hotin aur attacker payment ka message deta hai.

**Protection:**
- Important data ka backup rakhein.
- Software updated rakhein.
- Suspicious attachments se bachein.
- Access permissions limited rakhein.

### 4. Password Attack

Password attack mein attacker kisi account ka password guess karne ya chori karne ki koshish karta hai.

**Protection:**
- Har account ke liye unique password use karein.
- Password manager use kar sakte hain.
- MFA enable karein.
- Password kisi ke saath share na karein.

### 5. Denial-of-Service (DoS)

DoS attack mein system ya website ko itni requests bheji ja sakti hain ke woh legitimate users ko service dene mein fail ho jaye.

Distributed Denial-of-Service (DDoS) mein multiple systems mil kar attack karte hain.

**Protection:**
- Traffic filtering
- Rate limiting
- DDoS protection services
- Network monitoring

### 6. Social Engineering

Social engineering mein attacker logon ko manipulate karke confidential information hasil karta hai ya unse unsafe action karwata hai.

**Example:** Koi shakhs technical support ban kar call karta hai aur aapse password mangta hai.

**Protection:**
- Identity verify karein.
- Password aur OTP share na karein.
- Urgent ya suspicious requests ko verify karein.

## 8. What Is a Vulnerability?

### Definition

A vulnerability is a weakness in a system, application, network, or security process that could be exploited.

### Explanation

Vulnerability system ki aisi kamzori hoti hai jiska faida utha kar attacker nuqsan pohancha sakta hai.

### Examples

- Weak password
- Outdated software
- Incorrect firewall configuration
- Unnecessary open ports
- Application mein coding error

### Protection

- Software updates install karein.
- Strong authentication use karein.
- Security configurations review karein.
- Vulnerability assessments karein.

## 9. Difference Between Threat, Vulnerability, and Risk

### Threat

Threat aik potential khatra hai jo system ko harm kar sakta hai.

### Vulnerability

Vulnerability system ki kamzori hai jiska faida uthaya ja sakta hai.

### Risk

Risk is baat ka imkaan aur impact hai ke koi threat kisi vulnerability ka faida utha kar nuqsan pohanchaye.

### Real-Life Example

Maan lein aapke account ka password bohat weak hai.

- **Threat:** Attacker jo account access karne ki koshish kar sakta hai.
- **Vulnerability:** Weak password.
- **Risk:** Account compromise hone aur personal data chori hone ka imkaan aur uska nuqsan.

| Term | Meaning |
|---|---|
| Threat | Potential khatra. |
| Vulnerability | System ki kamzori. |
| Risk | Nuqsan hone ka imkaan aur uska impact. |

## 10. Authentication and Authorization

### Authentication

Authentication ka matlab user ki identity verify karna hai.

**Example:** Username aur password enter karna.

### Authorization

Authorization ka matlab decide karna hai ke authenticated user ko kin resources ya actions ki permission hai.

**Example:** Student sirf apne marks dekh sakta hai, lekin university ka record change nahi kar sakta.

### Difference

| Authentication | Authorization |
|---|---|
| User ki identity verify karta hai. | User ki permissions decide karta hai. |
| Sawal: Aap kaun hain? | Sawal: Aap kya kar sakte hain? |
| Example: Login. | Example: File access permission. |

## 11. Security Controls

Security controls woh measures hain jo systems aur data ko protect karne ke liye use hote hain.

### 1. Administrative Controls

Yeh policies, procedures aur training par mabni hote hain.

**Example:** Password policy aur employee security training.

### 2. Technical Controls

Yeh technology ke zariye security provide karte hain.

**Example:** Firewall, encryption aur MFA.

### 3. Physical Controls

Yeh physical devices aur locations ko protect karte hain.

**Example:** CCTV, locks aur access cards.

## 12. Best Cybersecurity Practices

1. Strong aur unique passwords use karein.
2. MFA enable karein.
3. Operating system aur software updated rakhein.
4. Unknown links aur attachments par click na karein.
5. Important files ka regular backup rakhein.
6. Public Wi-Fi par sensitive activities karte waqt ehtiyat karein.
7. Sensitive data ko encrypt karein.
8. Accounts ko sirf zaroori permissions dein.
9. Suspicious login alerts ko seriously lein.
10. Password, OTP aur recovery codes kisi ke saath share na karein.

## 13. Cybersecurity in Cloud Computing

Cloud computing mein data aur applications internet ke zariye cloud infrastructure par run karte hain.

Cloud security ka maqsad cloud resources ko unauthorized access, data loss aur cyberattacks se protect karna hai.

### AWS Security Examples

- **AWS IAM:** Users, roles aur permissions manage karta hai.
- **MFA:** Login ke liye extra verification provide karta hai.
- **Security Groups:** EC2 instances ke inbound aur outbound traffic ko control karte hain.
- **AWS KMS:** Encryption keys manage karne mein madad karta hai.
- **Amazon CloudWatch:** Metrics, logs aur monitoring provide karta hai.
- **AWS CloudTrail:** AWS account mein ki gayi API aur activity events ka record provide karta hai.

### Important Point

Cloud security mein cloud provider aur customer dono ki responsibilities hoti hain. In responsibilities ka taqseem cloud service aur configuration par depend karta hai.
